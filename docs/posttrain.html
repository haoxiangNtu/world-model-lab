VPP2 的后训练过程

从一个会生成好看视频的 Wan2.1-I2V-14B，到一个 0.22 秒出一段动作的机器人策略，中间是四步：先教它按详细描述预测整个操作事件，再改成预测固定 8 秒，再把 40 步采样蒸馏成 1 步，最后挂上动作专家。每一步解决的都是上一步留下的具体问题。

阶段 1 事件级实验：采样时间线阶段 2 固定时长一致性蒸馏3D：流匹配与蒸馏阶段 3 动作专家3D：三阶段流水线评测专项后训练

阶段 1 · 事件级持续预训练：先把映射学唯一

把 Wan2.1-I2V-14B 的全部参数拿来，在整理好的操作视频上继续训练。每条训练样本是一个完整的子任务：条件是首帧 o₀ 和详细描述 c，目标是从开始到完成的整段视频。

y_event = ( o₀, o_⌊T/N⌋, o_⌊2T/N⌋, …, o_T ) 在整个事件上均匀取 N 帧，T 是末帧 x₁ = E(y_event) Wan-VAE 编码成 latent x_s = (1 − s) ε + s x₁, ε ~ N(0, I), s ∈ [0,1] 流时间 s：0 是噪声，1 是数据 L_FM = E ‖ v_θ(x_s, s, c) − (x₁ − ε) ‖² 流匹配，和 Wan 原本的目标一样

为什么是"整个事件"而不是"接下来几秒"：描述说的是整件事（把杯子放进盒子），如果只预测接下来 2 秒，描述和画面对不上，模型又回到了短片段的多模态映射。论文的消融 VPP2-Fixed-Step 就是跳过这一阶段直接预测固定时长，指令跟随成功率从 0.80 / 0.90 掉到 0.48 / 0.42（人手 / 机器人）。

实验 1 · 事件级采样 vs 固定时长采样

一条示范有 T 帧。事件级采样在整段上均匀取 N 帧，所以事件越长、帧与帧之间隔得越久；固定时长采样从当前帧起按固定间隔取，超出事件末尾的位置全部截到最后一帧。拖动事件时长和片段起点，看两种采样取到哪些帧、帧间隔是多少。

帧间隔 δ
覆盖的时间范围
被截到末帧的采样点
2 s 动作片段对应的预测帧
数据集按 30 fps 画。固定 8 秒、N = 16 时 δ = 30 × 8 / 16 = 15 帧 = 0.5 秒，对所有事件都一样，于是 2 秒的动作片段永远对应前 4 个预测帧间隔。事件级采样的 δ 随事件时长从 0.06 秒变到 0.75 秒，动作没法按固定节奏对齐，这就是阶段 2 存在的原因。

阶段 2 · 固定时长后训练：给动作一个统一的时间刻度

H = 8 s（机器人）或 2 s（人手），f = 数据集帧率，δ = f·H / N y_chunk^(t) = ( o_t, o_{t+⌊δ⌋}, o_{t+⌊2δ⌋}, …, o_{t+⌊Nδ⌋} ) 索引超过 T 的截到 T 条件 c = 当前观测 o_t + 子任务描述；目标函数仍是 L_FM

这一阶段同时把视频输入降到 17 × 416 × 240，token 数从 5070 降到 1950。模型已经在阶段 1 学会了"按描述把事情做完"，阶段 2 只是改变它输出的时间刻度，不需要重新学语义。

一致性蒸馏：把 40 步压成 1 步

流匹配模型推理要沿速度场积分，Wan 默认 40 到 50 步，每步一次 14B 前向，机器人等不起。一致性模型的想法：训练一个函数 F_θ(x_s, s, c)，不管从路径上哪个点出发，都直接输出终点 x₁。约束是"同一条路径上相邻两个时刻的预测要一致"。

L_CD = E [ λ(s, s′) ‖ F_θ(x_s, s, c) − stopgrad( F_θ̄(x̂_s′, s′, c) ) ‖² ], 0 ≤ s < s′ ≤ 1 x̂_s′ = 用冻结的教师（阶段 2 的模型）从 (x_s, s) 沿速度场积分到 s′ θ̄ = 学生参数的 EMA（指数滑动平均），作目标时不回传梯度 边界条件 F_θ(x, 1, c) = x；以 0.5 的概率取 s′ = 1，强调单步生成 推理：x₁ = F_θ(ε, 0, c)，一次前向，约 0.12 s

3D 实验 2 · 流匹配的直线与一致性蒸馏的捷径

拖动旋转 · 滚轮缩放

灰点是噪声 ε ~ N(0, I)，蓝点是数据 x₁（这里用两个环代表 latent 的两个模式）。流匹配训练时把每个噪声点和一个数据点配对，沿直线 x_s = (1−s)ε + s·x₁ 插值，模型学的是每个点上的速度。拖动 s 看粒子从噪声走到数据。切换模式看教师怎么一步步积分、学生怎么一步跳到终点、一致性约束在约束什么。

阶段 3 · 动作专家预训练：挂上去，但别碰坏

视频模型变成单步生成器之后，才开始训练动作。动作专家是一个 0.9B 参数的扩散 Transformer，通过 MoT 架构和视频 DiT 共享注意力（原理见 MoT 页），以视频 DiT 的 KV cache 为条件，输出 2 秒的动作片段，用流匹配训练、5 步去噪推理。

数据
统一了工作空间和末端坐标系的双臂数据（ALOHA 式、人形、人类第一视角），占总数据 80% 以上。
冻结什么
动作训练初期冻结视频 DiT 的全部基础参数，视频主干只用 LoRA 适配。动作专家是新初始化的，开头的梯度是噪声，直接传进 14B 主干会破坏阶段 1、2 学到的表征。
训练什么
0.9B 动作 DiT 全部参数 + 视频 DiT 上的 LoRA。
为什么是隐式逆动力学
动作 token 在每一层同时看到当前观测的表征和预测未来的表征，相当于在问"从这里到那里要怎么动"。没有显式地先生成像素视频再做逆动力学，像素解码在控制回路里根本不需要跑。
延迟
视频单步 0.12 s + 动作 5 步 0.10 s = 0.22 s 出一段 2 秒动作；bfloat16 + torch.compile。

评测专项后训练

论文里的仿真评测（LIBERO、RoboDojo）用的是在各自训练集上再做一轮后训练的 VPP2：LIBERO 只用四个标准套件的示范，RoboDojo 按官方协议训练。这一轮和阶段 3 的做法相同，只是数据换成评测自己的示范。真实 ALOHA 的零样本评测则完全不做任务专项训练，直接部署阶段 3 的模型。VLM 子任务规划的版本还要把示范按子任务切开，每段配一条子任务描述再训练。
