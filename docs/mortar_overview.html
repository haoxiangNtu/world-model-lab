mortar 仿真器上的实验总览

截至 11-25 16 时：mortar 仿真器已经替换原来的仿真器，在五类机器人任务上完成了训练：全身动作跟踪、平地行走、搬箱子、跑酷教师（五个里 都已训完）、灵巧手拧瓶盖。训练代码都是论文的官方代码或同一套强化学习代码，训练部分不改，只换物理仿真器。结果分三种情况：和原仿真器持平的有全身动作跟踪（0.88 对 0.88）、平地行走（都不摔）、跑酷里的平地走跑和上台阶教师（99.4–99.6 % 对 99.1–99.5 %）、灵巧手拧瓶盖（四种输入里三种持平，原始触觉那一种 mortar 的波动更大）；搬箱子带两项接入修正后的一次训练完整做完 65.0 %（同样数据量，一个随机种子，检查点之间波动大）；修正之前的两次在同样数据量下和 Isaac Sim 的对照相近（18.0 % / 26.3 % 对 32.9 % / 22.7 %），低于 MuJoCo 的对照（52.6 %）；爬高台的跑酷教师第一次没有学会，原因是我们接入时的一处遗漏，修正后重新训练，两个都已训完：慢速 98.2 %、快速 96.3 %（Isaac Sim 的对照 98.9 % / 97.0 %）。速度上，mortar 比这些任务原来用的 GPU 刚体仿真器慢 6–17 倍。还没有做完的：跑酷的学生（训练到第 15000 / 30000 轮后暂停，放进 MuJoCo 测试上台阶 99.0 %、爬高台 100.0 %，已和作者发布的学生相当）、RPL 的斜坡专家（训练到第 9324 / 50000 轮后暂停），见最后一节。这一页把各页面的结果按“策略是在哪个仿真器里训练的”分组；“只是放进 mortar 测试”和“用 mortar 训练”分开列，不混在一起。所有数字都是仿真里的，没有真机实验。

四、速度

结果：mortar 比这些任务原来用的 GPU 刚体仿真器慢 6–17 倍，所以同样的训练要用更多显卡或更长时间。

五、我们接入时出过的错

为什么列出来：把 mortar 接进各套训练代码的工作是我们做的。下面这些错都出在我们的接入上，每一处都让某个结果先偏差、后更正；受影响的数字都已重做或在原页面标注。

  • 接触刚度沿用了默认值，对 G1 由细胶囊组成的脚底偏软：MuJoCo 训练的行走策略放进 mortar 有 31.2–36.6 % 摔倒过，提高 3 倍后降到 0.1–0.5 %（详情）。
  • 摩擦的切向刚度一直没有设置，比接触刚度软 30 倍：调到相同后，换仿真器的损失明显变小（详情）。
  • 箱子的表面只用了 12 个大三角形，箱子陷进地面约 10 厘米：细分表面后正常，之前的两次搬箱子训练作废重做（详情）。
  • 从动作中途重置时，机器人或箱子和障碍、手有几厘米重叠，被直接推开后弹飞：重置后的头几个物理步里限制速度变化。跑酷的爬高台教师因此第一次没有学会（详情），搬箱子抱着箱子重置时箱子被弹走（详情）。
  • 脚底的碰撞外形太粗或太细：RPL 的脚底板只有 12 个三角形时石墩上只有 48 % 的回合走满时限，细分后 99.6 %（详情）；七根细胶囊做脚底时脚踩不平，换成细分的脚底板后好转（搬箱子，接触测试）。
