MoT 的原理：参数分家，注意力共享

VPP2 的动作专家是"通过 MoT 架构"挂到视频 DiT 上的。MoT 的想法只有一句话：不同模态的 token 各用各的权重，但在同一个注意力矩阵里互相看。这一页先讲原始论文，再讲机器人领域怎么用它（π0、Cosmos 3、VPP2 都是同一个套路），最后用 3D 看清 VPP2 里一个视频 token 和一个动作 token 各走了什么路。原文见 arXiv 2411.04996。

1. MoT 是什么

原始论文（Meta FAIR 与斯坦福，Weixin Liang 等）要解决的问题是：一个稠密 Transformer 同时学文本、图像、语音，各模态的训练动态互相冲突，占据不同的特征空间，需要远多于纯文本模型的数据和算力。MoT 的做法：

  1. 按模态拆开所有非嵌入参数。FFN、注意力的 q、k、v、o 投影、LayerNorm，每种模态各一套。文本 token 永远走文本那套，图像 token 永远走图像那套，路由由 token 的模态决定，是确定的，没有学习出来的路由器。
  2. 注意力仍然是全局的。各模态的 q、k、v 算完之后拼成一个序列，做同一个自注意力。所以跨模态的信息交换一点没少，只是"怎么算 q、k、v"和"注意力之后怎么处理"分开了。
  3. 计算量按模态比例分配。每个 token 只过自己那一套参数，总 FLOPs 和同宽度的稠密模型相当，但每套参数只需要拟合一种模态，收敛更快。
设定（论文中的实验）结果
Chameleon 7B，文本 + 图像生成MoT 用 55.8% 的 FLOPs 达到稠密基线的水平
再加语音语音质量相当，只用 37.2% 的 FLOPs
Transfusion 设定（文本自回归 + 图像扩散，目标函数不同）7B MoT 用 1/3 FLOPs 达到稠密的图像质量；760M MoT 在关键图像指标上超过 1.4B 稠密模型
AWS A100 实测墙钟时间达到稠密基线的图像质量用 47.2% 的时间，文本质量用 75.6% 的时间

最后一行对机器人最有意思：Transfusion 设定里文本是自回归目标、图像是扩散目标，两种目标函数在同一个网络里训练，MoT 依然有效。VPP2 的情况与此类似：视频 token 已经是去噪好的 latent，动作 token 在做流匹配去噪。

第三列最后一行就是机器人领域用 MoT 的方式：视频模型或 VLM 已经预训练好了，动作是一个新模态，给它单独一套参数，让它通过共享注意力读预训练模型的表征，而不去改预训练模型本身。

单向掩码的后果是：视频 token 这一路的计算和纯视频模型完全一样，动作 token 的存在对它没有任何影响。于是视频塔的前向只需要算一次，它每层的 key、value 存成 KV cache，动作塔做 5 步去噪时反复读这份缓存。视频先验没有被动作训练碰过，推理也不用重复 14B 的前向。

VPP2（2026）Wan2.1-I2V-14B 视频 DiT0.9B 动作 DiT，流匹配视频看不到动作；动作看视频和动作视频塔冻结 + LoRA，动作塔读视频塔的 KV cache

三者的共同点：新模态的 token 要"读"预训练模型的中间表征，而不是只读它的最终输出。读中间表征的最自然方式就是共享注意力，又不想让新模态的梯度改坏预训练塔，于是参数分家、掩码单向。VPP2 的基线之一 Cosmos3-64B 本身也是 MoT，只是它的生成塔同时管视频和动作。

5. VPP2 的具体做法

动作专家
一个 0.9B 参数的扩散 Transformer，标准 MoT 结构，随机初始化。输入是加噪的 2 秒动作片段，目标是流匹配的速度场，推理 5 步去噪，约 0.10 秒。
条件
视频 DiT 处理"当前观测 + 单步生成的未来 latent"，每一层的 key、value 组成 KV cache；动作 token 在每一层的共享注意力里读它。这就是论文说的"以视频模型的 KV cache 为条件学习隐式逆动力学模型"：给定现在和未来的画面，推断中间的动作。
保护视频塔
动作训练初期冻结视频 DiT 的全部基础参数，只用 LoRA 适配视频主干。原因是动作专家刚初始化时梯度很乱，直接传进视频塔会破坏预训练表征。
统一坐标
动作是在统一后的末端坐标系里表示的（见导读页 3D 实验 2），所以一套动作专家能吃超过 80% 的双臂第一视角数据。
延迟
视频单步 0.12 秒 + 动作 5 步 0.10 秒 = 每个 2 秒动作片段约 0.22 秒，bfloat16 加 torch.compile。

把它和 VPP1（Video Prediction Policy，2024）比：VPP1 从视频扩散模型的中间层抽特征，再喂给一个独立的扩散策略头；VPP2 把这一步换成共享注意力，动作 token 自己决定看哪一层、哪些位置的视频表征，而不是预先指定取哪一层。
