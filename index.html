通过拆一篇论文来理解世界模型

这是一份学习记录，线索是 2026 年 10 月的论文 Video Prediction Policy 2：一个把视频生成模型变成机器人策略的世界动作模型。顺着它往下挖，会碰到视频基础模型的结构（Wan2.1）、把新模态挂到预训练模型上的架构（MoT）、从生成模型到策略的后训练流程，以及这个领域怎么评测泛化。每一页都带可以拖动、点击的 3D 实验。姊妹站：LLM Inference Lab。

论文导读
VPP2 讲了一个什么故事：世界动作模型为什么在开放场景里会动错，详细描述和事件级预测怎么把映射变唯一，三阶段训练，三组结果。3D：同一起点的轨迹分布、两个数据集的坐标系对齐。
Wan2.1 架构
Wan-VAE 的 4×8×8 压缩、40 层 DiT 里的三件事、umT5 与 CLIP 两路条件、流匹配目标，用权重文件大小对出 I2V 实际 16.4B。3D：整张 I2V-14B 的一次前向，点模块看形状和参数量；像素到 token 的压缩、一个 block 的内部。
MoT 原理
参数分家、注意力共享：原始论文的结果，和 MoE 的区别，π0、Cosmos 3、VPP2 共用的套路，单向掩码与 KV cache。3D：跟着一个视频 token 和一个动作 token 走过双塔。
后训练过程
事件级持续预训练、固定时长后训练、一致性蒸馏、动作专家预训练、评测专项后训练，每一步解决上一步留下的什么问题。实验：采样时间线、流匹配与蒸馏的 3D 粒子、三阶段参数冻结图。
评测数据集
视频预测指令跟随、真实 ALOHA 零样本、LIBERO 的 ID / Pro / OOD 三种考法、RoboDojo 的五个能力维度各在考什么，附论文全部结果图。3D：一张桌子六种考法、双臂桌面五个维度。
复现实验：OpenWAM-α 与 MolmoAct2
在 4 张 A800 上复现一个世界动作模型（OpenWAM-α）和一个 VLA（MolmoAct2 / Think）。OpenWAM-α 从基座重新训练后 LIBERO 99.45 %（论文 99.3）；发布权重各跑 2000 次：99.0 / 97.0 / 97.7 %，与论文差 0.2–0.4；四组任务各考什么（40 段示范视频）、三模型并排视频、按原配方重新训练的进度。
复现实验：LingBot-Touch 触觉基础模型
页面分成总览和七个分节，每节开头说明做了什么和结果。最新（11-22）：第 7 节的种子补齐了，同一个 Sharpa 手拧瓶盖任务在 Isaac Sim（PhysX）和 mortar 里各训练 17 次：在各自的仿真器里成功率接近（盖子转满一圈，各个种子的平均：不给触觉 PhysX 78.3 %、mortar 79.7 %；CNN 91.0 % 对 90.2 %；二值接触 92.3 % 对 87.7 %；原始触觉 92.6 % 对 85.9 %），mortar 训练慢约 6.4 倍，策略原样换到另一个仿真器后两个方向都掉得多（各种输入平均只剩 19–47 %）；含三段对比视频。mortar 里“手先找到盖子再拧”训练完 6000 万步，8 次都学会（85.7–99.6 %），画面在第 6 节。含效果视频（策略转圆柱、mortar 抓取、自建的拧瓶盖）。核对开源权重；把冻结的触觉编码器接到同事的 mortar 仿真器（两指夹爪、五指手）和 Sharpa 手的 Isaac 仿真触觉上做 probe：预训练权重明显好于同结构的随机权重，但不比原始信号上的小网络好。论文表 3 的 in-hand rotation 强化学习对比已全部完成（单圆柱和九种形状 × 三种尺度两个版本，五种输入各三个种子）：单圆柱上冻结的 LingBot 编码器 84.6 ± 3.8 %，和与策略一起训练的 CNN（85.5 ± 3.6）打平；九物体上 LingBot 49.8 ± 9.3，CNN 59.0 ± 7.7，无触觉 4.3 ± 3.7。触觉有用、LingBot 明显好于无触觉成立，LingBot 自己的成功率和论文（56.4 ± 7.5）接近，但“好于 CNN”没有复现：论文里 CNN 只有 26.6 ± 23.1，我们的重建里基线高得多。按论文方法从零重新预训练已完成，probe 上和官方权重相当。预训练设置的消融 10 组也已完成。另外自建了 PhysX 里的触觉拧瓶盖任务：不带螺纹的版本用官方编码器 99.7 % 拧满 2 圈；带螺纹、要拧开后提起瓶盖的版本，用冻结的官方编码器三个种子里两个训练成功（98.2 % 和 98.8 %），一个学成了只拧不提；不给触觉的策略是 70–93 %，主要输在提起以后又松手，其余带触觉的训练多数在 94 % 以上、彼此分不出高下；又做了一个瓶盖形状和大小各不相同的更难的版本，五种输入各三个种子：无触觉 34.8 ± 12.1，CNN 83.0 ± 5.9，冻结的官方编码器 76.6 ± 4.2，页面上有一次“只转不提”的奖励设置和改回之后的对比视频，11-19 又加了两段视频：九种不同形状的瓶盖上无触觉、CNN、LingBot-Touch 三种策略的并排对比，以及 27 个瓶子倒挂、由脚本拉拽和转动瓶盖的螺纹演示（螺纹是约束而不是几何，演示的是它的力学效果：拉不掉，每圈移动 4 毫米，1.5 圈后脱开）。mortar 仿真器里的拧瓶盖任务（五指手，触觉来自 FEM 软垫的形变）第一批 8 次训练已结束：五种输入评测都在 87–100 %（不用触觉的种子 0 也是 100 %，这一版只有一种瓶盖），触觉让学会的速度快约 1.5–2 倍；页面上有五种输入的并排视频和不用触觉时掉盖的视频。
总览：mortar 仿真器上的实验（按仿真器分组）
所有涉及 mortar 仿真器的实验，按策略在哪个仿真器里训练分组。用 mortar 训练的：全身动作跟踪（0.88，MuJoCo 0.88）、平地行走（不摔）、搬箱子（18.0 % / 26.3 %，Isaac Sim 同样数据量 32.9 % / 22.7 %，MuJoCo 52.6 %）、PHP 跑酷教师（五个里 3 个已训完）、灵巧手拧瓶盖（已完成）；PHP 学生和 RPL 专家已排期。只在 mortar 里测试的、速度（慢 6–17 倍）和我们接入时出过的错分开列出。
复现实验：RPL 感知行走 × mortar（接入已验证，训练未开始）
含策略视频。RPL 的官方训练代码用 IsaacGym；把物理仿真器换成 mortar 的接入已完成并验证（11-23 7 时）：作者发布的四个专家策略原样放进 mortar，99.8 % 的回合走满时限，IsaacGym 里是 99.9 %，石墩、斜坡、上下台阶都对得上。查出并改正了我们接入时的一处错误（脚底外形太粗，改正前石墩上只有 48.3 %）。用 mortar 训练还没有开始。
对照测试：接触和摩擦，mortar 与 MuJoCo
G1 的一只脚（七根细胶囊）在平地上做五项有标准答案的测试。摩擦：推力低于极限时 mortar 里脚不动，MuJoCo 用行走任务默认的金字塔摩擦锥会每秒滑 0.18–1.17 毫米、斜向推到 90 % 就滑走，换成椭圆摩擦锥后接近 mortar。支撑：MuJoCo 几乎刚性；mortar 在我们任务用的设置下陷入 0.5 毫米，俯仰力矩到理论值的 95 % 就翻倒。滑动和刹车距离两边都在几个百分点内。11-23 补充：把这只脚换成表面细分的脚底板后，mortar 的下陷降到 0.05 毫米，力矩到一半时的倾角从 1.24° 降到 0.068°：支撑偏软大部分来自细胶囊脚底；接近翻倒时仍比 MuJoCo 软。
复现实验：用 mortar 训练 PHP 跑酷教师（进行中）
PHP 跑酷的官方训练代码不改训练部分，只把物理仿真器从 Isaac Sim 换成 mortar（11-24 3 时）。平地走跑第 19999 轮：在 mortar 里 99.4 %，放进 Isaac Sim 95.5 %；上 36 cm 台阶，慢速第 19999 轮：在 mortar 里 99.4 %，放进 Isaac Sim 96.0 %；上 36 cm 台阶，快速第 19999 轮：在 mortar 里 99.6 %，放进 Isaac Sim 96.2 %；爬 76 cm 高台，慢速第 15000 轮：在 mortar 里 98.8 %；爬 76 cm 高台，快速第 12500 轮：在 mortar 里 80.3 %，放进 Isaac Sim 80.1 %。Isaac Sim 训练满 2 万轮的教师是 97.0–99.5 %。其余教师还在训练或排队。按每张显卡算，mortar 的速度约为 Isaac Sim 的五到十分之一。
复现实验：用 mortar 训练 FastSAC（行走、搬箱子）
含策略视频。FastSAC 的官方代码不改训练部分，只把物理仿真器换成 mortar。G1 平地行走训练 2 万轮：用 mortar 训练的策略在 mortar 里没有一个摔倒，原样放进 MuJoCo 没有一个摔倒、放进 Isaac Sim 有 0–0.1 % 摔倒过；用 MuJoCo 训练的对照放进 mortar 后有 31.2–36.6 % 摔倒过，原因已查到，是我们给 mortar 设的脚底接触偏软（接触刚度提高 3 倍后降到 0.1–0.5 %）。同一张显卡上 mortar 每秒 1.5 万个环境步，MuJoCo Warp 14.1 万。搬箱子（6 万轮，同样数据量）：用 mortar 训练的两个种子在 mortar 里完整做完 18.0 % 和 26.3 %，Isaac Sim 对照 32.9 % 和 22.7 %，MuJoCo 对照 52.6 %；mortar 和 Isaac Sim 的失败都集中在箱子离地之前。
复现实验：人形行走三篇（FastSAC / RPL / PHP）
含策略视频。FastSAC“15 分钟训出行走”已复现：G1 上训练 14 分钟基本不摔（0.1–0.3 %），PPO 同样时间还有 14–29 % 摔倒；同一篇的搬箱子（全身动作跟踪）也已完成：训练曲线上 FastSAC 快得多，但去掉噪声评测时 PPO 完整做完的比例更高（72 % 对 61 %）。RPL 感知行走的学生蒸馏到第 4000 轮，在 MuJoCo 赛道上接近作者发布的学生，已暂停。PHP 跑酷的五个教师训完（片段完成率 97.0–99.5 %），学生未开始。
复现实验：SuperMimic 全身动作跟踪
含策略视频。11-21 用论文作者公开的官方代码在 MuJoCo 里重跑：G1 跟踪 LAFAN1 的 40 段动作，训练 3 小时归一化回报 0.87 和 0.88（论文 0.82），40 段全部走完。把策略原样放进 mortar 仿真器：能看到完整状态的策略 0.80（摔 3 段），只用机载传感器的策略 0.61（摔 16 段）；这两个数是在我们给 mortar 设得偏软的脚底接触下测的，接触刚度提高 3 倍后是 0.82 和 0.75。把官方代码的仿真器换成 mortar 来训练（11-22 完成）：同样的数据量下，mortar 训练的策略在 mortar 里是 0.87 / 0.87 和 0.86，和 MuJoCo 版的 0.88 和 0.87 持平。按调硬后的接触和摩擦设置重新训练（11-23）：在 mortar 里 0.88 / 0.88 和 0.87，原样放进 MuJoCo 是 0.87 / 0.85 和 0.86，换仿真器基本不掉了。此前用社区代码做的第一版（0.57 和 0.84）另有一页。

建议的学习路径

  1. 先读论文导读，在 3D 实验 1 里切换"简短指令"和"详细描述"，理解论文的核心观察。
  2. 打开 Wan2.1 架构，先在实验 1 里看整张 I2V-14B 的数据流，再在实验 2 里把帧数和分辨率拨到 VPP2 的配置，看 token 数怎么掉到 1950。
  3. 读 MoT 原理，在 3D 里跟一个动作 token 走一层，再切到"推理：KV cache"看执行顺序。
  4. 读后训练过程，用实验 1 理解为什么要两阶段采样，用实验 2 理解蒸馏成单步的含义。
  5. 看评测数据集，在 LIBERO 场景里切换六种设定，再看结果图里哪些数字真正说明泛化。
  6. 遇到"为什么"翻原理问答。
