World Action Model · VPP2 · 2026-10

通过拆一篇论文来理解世界模型

这是一份学习记录，线索是 2026 年 10 月的论文 Video Prediction Policy 2：一个把视频生成模型变成机器人策略的世界动作模型。顺着它往下挖，会碰到视频基础模型的结构（Wan2.1）、把新模态挂到预训练模型上的架构（MoT）、从生成模型到策略的后训练流程，以及这个领域怎么评测泛化。每一页都带可以拖动、点击的 3D 实验。姊妹站：LLM Inference Lab。

论文导读
VPP2 讲了一个什么故事：世界动作模型为什么在开放场景里会动错，详细描述和事件级预测怎么把映射变唯一，三阶段训练，三组结果。3D：同一起点的轨迹分布、两个数据集的坐标系对齐。
Wan2.1 架构
Wan-VAE 的 4×8×8 压缩、40 层 DiT 里的三件事、umT5 与 CLIP 两路条件、流匹配目标，用权重文件大小对出 I2V 实际 16.4B。3D：整张 I2V-14B 的一次前向，点模块看形状和参数量；像素到 token 的压缩、一个 block 的内部。
MoT 原理
参数分家、注意力共享：原始论文的结果，和 MoE 的区别，π0、Cosmos 3、VPP2 共用的套路，单向掩码与 KV cache。3D：跟着一个视频 token 和一个动作 token 走过双塔。
后训练过程
事件级持续预训练、固定时长后训练、一致性蒸馏、动作专家预训练、评测专项后训练，每一步解决上一步留下的什么问题。实验：采样时间线、流匹配与蒸馏的 3D 粒子、三阶段参数冻结图。
评测数据集
视频预测指令跟随、真实 ALOHA 零样本、LIBERO 的 ID / Pro / OOD 三种考法、RoboDojo 的五个能力维度各在考什么，附论文全部结果图。3D：一张桌子六种考法、双臂桌面五个维度。
原理问答
14B 为什么赢 64B、1950 个 token 和 0.12 秒怎么算、为什么不直接固定时长、一致性蒸馏在约束什么、8 秒与 2 秒的关系、MoT 与 MoE、LoRA、LIBERO 98% 为什么不算泛化。

建议的学习路径

  1. 先读论文导读，在 3D 实验 1 里切换"简短指令"和"详细描述"，理解论文的核心观察。
  2. 打开 Wan2.1 架构，先在实验 1 里看整张 I2V-14B 的数据流，再在实验 2 里把帧数和分辨率拨到 VPP2 的配置，看 token 数怎么掉到 1950。
  3. 读 MoT 原理，在 3D 里跟一个动作 token 走一层，再切到"推理：KV cache"看执行顺序。
  4. 读后训练过程，用实验 1 理解为什么要两阶段采样，用实验 2 理解蒸馏成单步的含义。
  5. 看评测数据集，在 LIBERO 场景里切换六种设定，再看结果图里哪些数字真正说明泛化。
  6. 遇到"为什么"翻原理问答。
